## 두 가지 수확 방식

### 1. 비례 수확 (constant effort) — 초임계 분기 transcritical

```
dN/dt = rN(1 − N/K) − hN = N·((r − h) − (r/K)N)
```

| | |
|---|---|
| 평형점 | `N = 0`, `N = K(1 − h/r)` |
| 분기점 | **h\* = r** |
| h < r | 0은 불안정, `K(1−h/r)`가 안정 → 지속 가능 |
| h > r | 두 평형점이 안정성을 **맞바꿈**. 0이 유일한 안정 평형 → 멸종 |
| 지속 수확량 | `Y(h) = hK(1 − h/r)`, `h = r/2`에서 최대 `rK/4` (MSY) |

수확을 늘리면 평형 개체수가 **연속적으로** 0을 향해 줄어들기 때문에, 붕괴 전에 경고가 보입니다.

### 2. 정량 수확 (constant yield) — 안장-마디 분기 saddle-node

```
dN/dt = rN(1 − N/K) − H
```

포물선 전체가 아래로 **H만큼 평행이동**합니다.

| | |
|---|---|
| 평형점 | `N± = (K/2)(1 ± √(1 − 4H/rK))` |
| 분기점 | **H\* = rK/4** (포물선 꼭짓점 높이 = MSY) |
| H < H\* | 큰 근 `N+`는 안정, 작은 근 `N−`는 불안정한 **멸종 문턱**(분리선) |
| H = H\* | 두 근이 `N = K/2`에서 충돌해 소멸 |
| H > H\* | **평형점이 아예 없음** → 어떤 초기값에서도 유한 시간 안에 붕괴 |

비례 수확과 달리 평형 개체수가 `K/2`인 상태에서 **경고 없이** 통째로 사라집니다.
MSY 바로 근처에서 조업하는 것이 왜 위험한지 보여주는 고전적인 예입니다.

## 화면 구성

1. **성장 속도 곡선 f(N)** — 순수 로지스틱(점선), 수확 곡선(주황), 그 차이인 f(N)(파랑)을 겹쳐 그립니다.
   교점이 평형점, x축 위 화살표가 위상선(phase line).
2. **시간 궤적 N(t)** — RK4 수치적분. 여러 초기값을 함께 그려, 정량 수확에서 멸종 문턱 위/아래로 갈리는
   분리선(separatrix)을 눈으로 확인할 수 있습니다.
3. **분기 다이어그램** — 가로축이 수확 강도, 세로축이 평형 개체수.
   비례 수확은 두 가지가 교차하는 X자(초임계), 정량 수확은 두 가지가 만나 끝나는 접힘(안장-마디)이 나타납니다.
4. **1인당 성장률** — 비례 수확은 직선이 h만큼 내려가고, 정량 수확은 `H/N` 때문에 왼쪽에서 −∞로 발산합니다.

## 3D 확장 ([`3d.html`](3d.html))

2D 페이지는 파라미터 하나만 움직이며 평형점을 봅니다. `3d.html`은 **두 번째 파라미터를 축에 추가**해
평형 개체수 `N*`을 곡면의 높이로 그립니다 — 안장-마디 분기점이 곡면이 접히는 능선(**fold curve**)으로
드러납니다. 드래그로 회전, 스크롤로 확대/축소.

### 1. 안장-마디 접힘 곡면 — 축: `H · K · N`

```
dN/dt = rN(1 − N/K) − H
```

K를 고정한 단면이 2D 페이지의 분기 다이어그램과 정확히 같은 곡선입니다.
분기점 `H* = rK/4`가 제어변수 평면(H–K)에서 원점을 지나는 직선이 되고, 그 아래는 평형 2개 / 위는 0개입니다.

### 2. 알리 효과 쌍안정성 — 축: `h · A · N`

```
dN/dt = rN(1 − N/K)(N/A − 1) − hN
```

알리 효과(개체수가 임계값 `A` 아래로 떨어지면 성장률이 음이 됨)에 **비례** 수확을 결합한 모델입니다.
`−hN`은 `N=0`에서 정확히 0이 되므로 **멸종 상태가 h와 무관하게 항상 안정 평형으로 남고**,
나머지 두 평형(불안정 문턱 + 그 위의 안정 평형)이 `h*(A) = r(1−A/K)²/(4A/K)`에서 접혀 사라집니다.
→ h를 다시 낮춰도 회복되지 않는 **진짜 이력현상(hysteresis)**. 유전자 스위치·세포 운명 결정과 구조적으로 대응됩니다.

> 정량 수확(`−H`)으로는 이 쌍안정성이 나타나지 않습니다. `H>0`이면 `N=0`이 평형 자체가 아니기 때문에
> 평형 3개가 성립하는 곳이 `H=0`인 한 점뿐입니다. **같은 알리 효과라도 수확 방식에 따라 결론이 완전히
> 달라지는** 이 대비는 그 자체로 좋은 수업 소재입니다 — 유도 과정은 [`THEORY.md`](THEORY.md) 9장 참고.
